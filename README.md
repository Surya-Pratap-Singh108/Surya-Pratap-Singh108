## 🚀 Featured Projects

### Snitch: Full-Stack E-Commerce Platform

Dual-role Seller/Buyer platform with multi-variant products, Google OAuth 2.0, Razorpay payments and OTP-based email verification.

**Tech:** React, Node.js, Express.js, MongoDB, Redux Toolkit, Tailwind CSS, Razorpay<br>
**Links:** [GitHub](https://github.com/Surya-Pratap-Singh108/Snitch) · [Live](https://snitch-tawny.vercel.app/)

### DocuFlow: AI-Powered Document Workspace (RAG)

Upload PDFs and get grounded answers with similarity scores and source chunks, using Gemini embeddings and MongoDB Atlas Vector Search. Includes JWT authentication, Redis rate limiting, Docker and GitHub Actions CI/CD.

**Tech:** MERN, Gemini API, MongoDB Atlas Vector Search, Redis, Docker, GitHub Actions<br>
**Links:** [GitHub](https://github.com/Surya-Pratap-Singh108/DocuFlow) · [Live](https://docuflow-frontend-orcin.vercel.app/)

### AI Battle Arena: Multi-Model AI Evaluation Platform

Compare Mistral and Cohere responses side by side, orchestrated with LangGraph and evaluated by Gemini with structured output validated by Zod schemas.

**Tech:** TypeScript, Node.js, Express.js, LangGraph, Gemini, Mistral, Cohere, React, Zod<br>
**Links:** [GitHub](https://github.com/Surya-Pratap-Singh108/AI-Battle_Arena) · [Live](https://ai-battle-arena-bay.vercel.app/)
